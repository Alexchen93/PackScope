# PackScope 0.2.0 開發版

PackScope 是使用 PyQt5 的 Ubuntu 軟體管理介面。

## 啟動

```bash
cd PackScope
./packscope.sh
```

## 使用

- 按「安裝軟體」選擇本機 `.deb`、`.snap`、`.flatpak`、`.flatpakref` 或 `.AppImage` 檔案，程式會依副檔名選擇套件管理器，安裝完成後重新掃描清單。Flatpak 檔案安裝至目前使用者；AppImage 會複製到 `~/Applications` 並建立桌面捷徑。本機 Snap 使用 `--dangerous`，不驗證商店簽章；某些 Snap 可能另有安裝限制。
- 按「安裝軟體」右側的箭頭，選「依名稱安裝」可使用原有的來源安裝方式：APT 可搜尋套件，Snap、Flatpak、pipx、npm 和 Cargo 可輸入名稱或 ID。
- 按「檢查更新」後，各來源結果直接顯示在原本表格的「可用更新」欄，勾選一個或多個項目，再按「更新勾選項目」。右側顯示目前及可更新版本；目前不提供更新日誌。可用「僅顯示可更新」篩選及「勾選目前顯示的更新」批次勾選；其他篩選條件隱藏的勾選項目仍保留並計入更新數量。按「清除勾選」可清除所有項目。按「重新取得套件資訊」會重新取得 APT 及 Flatpak 的來源資訊；Snap 以自己的服務查詢。Flatpak 未提供版本時顯示「可更新」，右側顯示「未知」。重新掃描會清除過期的更新結果及勾選。
- 「更新選項」在按下「檢查更新」後出現在來源分類右側；篩選、勾選、重新取得套件資訊及執行更新皆在此選單中，選單按鈕顯示已勾選數量。
- APT 安裝、更新及移除在確認前會顯示目前本機套件清單的模擬結果，可展開查看完整變更。模擬失敗時會明確警告並以「否」作為預設選項；其他來源不會假裝有 APT 預覽。模擬與實際執行之間仍可能因套件清單變更而有差異。
- 使用「來源」與「類型」下拉選單篩選；類型預設為「僅顯示應用程式」，依桌面啟動項目或來源資料辨識，資料不完整時可改選「顯示全部套件」。選擇「開發工具」會自動顯示該類工具。來源選單的數字反映目前搜尋與類型篩選條件。
- 各來源會在背景並行掃描；部分來源失敗不影響其他來源。出現「查看掃描問題」時可查看原因並重新掃描。輸入搜尋文字後會稍等片刻才更新結果。
- AppImage 清單會標示由 PackScope 或 bauh 管理的項目，以及僅偵測到的檔案；後者不代表已整合至系統。
- 從清單選擇項目，按「開啟」、「更新」或「移除」。只有辨識到可用啟動方式的應用程式才能開啟。AppImage 移除會將檔案及 PackScope 建立的捷徑移至垃圾桶；AppImage 不提供統一的更新操作。
- 需要管理員權限時，Ubuntu 會開啟系統授權視窗供輸入密碼。PackScope 不接收或保存密碼。
- 套件操作沒有強制逾時或中止按鈕，以免打斷 APT/dpkg 交易。若長時間沒有輸出，請檢查 Ubuntu 授權視窗、網路及輸出紀錄；作業期間關閉視窗會被延後，可先最小化並等待完成。
- 視窗下方固定顯示輸出紀錄；開啟程式時是空白的，之後保留本次執行期間的操作與輸出。操作在背景執行，進度列顯示實際指令及即時輸出，完成後重新整理清單。能取得百分比時顯示該階段的進度；管理器未提供百分比時顯示執行中動畫。
- 每次啟動會建立獨立操作日誌，預設位於 `~/.local/state/packscope/logs/`（若設定 `XDG_STATE_HOME`，則位於其下的 `packscope/logs/`）。按「操作日誌」可查看本次檔案位置。日誌包含操作和套件管理器輸出，可能有本機路徑或其他個人資訊，分享前請先檢查；系統授權密碼不由 PackScope 接收。日誌不會自動刪除，可自行管理。
- 按「切換主題」可選擇深色、淺色或自訂配色；自訂時可調整背景、面板、文字、重點色及輸出欄顏色。主題、搜尋與來源篩選、清單欄寬和分割面板大小會在下次啟動時保留。
- 可以搜尋、篩選、排序、查看詳細資料，查詢更新、查看 APT 變更紀錄，以及匯出 JSON、CSV、Markdown。上方工具列的問號統一說明各個軟體來源。

## 範圍與依賴

需要 Python 3、PyQt5、程式所需的 Python 相依套件，以及所使用來源的系統工具。部分系統工具可能未安裝。系統權限操作需要 `pkexec` 和可用的圖形化 polkit 授權代理。

APT 清單包含系統程式庫；Flatpak 也包含執行環境。AppImage 僅掃描 `~/Applications`、`~/AppImages`、`~/Downloads` 第一層和 bauh 安裝紀錄。開發工具只涵蓋目前使用者的 pipx、目前 PATH 中 npm 的全域環境與目前 CARGO_HOME。

APT 更新查詢使用本機套件清單，Flatpak 使用本機快取，Snap 會連線查詢。AppImage 與開發工具的統一更新查詢尚未提供；個別開發工具的更新按鈕會呼叫其管理器。依桌面項目辨識應用程式可能有遺漏，並非完整的套件分類。

## 製作 Ubuntu 安裝套件

在已安裝 `dpkg-deb` 的 Ubuntu 電腦上，從專案根目錄執行 `sh packaging/build-deb.sh`。產生的檔案位於 `dist/`；安裝後可從應用程式選單或執行 `packscope` 開啟。Flatpak、Snap 等來源仍需要各自的套件管理器。

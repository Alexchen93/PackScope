# 操作與驗證說明

PackScope 使用對應套件管理器執行安裝、更新和移除，系統權限操作透過 Ubuntu polkit / pkexec 授權。指令以參數陣列執行，不使用 shell 串接；密碼由系統授權代理處理。

APT、Snap、Flatpak、pipx、npm、Cargo 操作的命令建構和介面背景流程已以模擬呼叫進行自動測試。AppImage 的安裝、桌面捷徑及移至垃圾桶已在暫存使用者目錄中實測。Flatpak 使用自建的本機測試來源與獨立使用者目錄，實測安裝、更新至新提交及移除。原生 polkit 密碼視窗與圖形介面的完整流程尚未進行端到端測試。

2026-10-31 曾以 Ubuntu 24.04 隔離虛擬機及測試套件驗證 APT 本身的安裝、升級、移除和依賴模擬；該測試不是 PackScope 圖形介面與授權流程的端到端驗證，腳本保存在 `tests/vm/user-data`。

0.2.0 開發版另在離線 Ubuntu 24.04 虛擬機中使用 PackScope 的操作程式碼，實際安裝、升級及移除自建 APT 測試套件；虛擬機以 root 執行並用測試替身取代 pkexec，因此不代表已驗證桌面授權視窗。DEB 安裝檔的檔案和捷徑亦在虛擬機中檢查；由於測試映像缺少 GUI 依賴，未在虛擬機中完成 GUI 啟動驗證。
